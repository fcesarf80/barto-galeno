# 🐓 Bartô Galeno

## O galo que transforma escolhas em reflexões!

Quiz interativo gamificado desenvolvido em Kotlin para Android.

O objetivo do projeto é apresentar, de forma divertida e interativa, situações relacionadas ao comportamento em grupo, utilizando um personagem inspirado no tradicional Galo de Barcelos e no famoso cantor e compositor brasileiro de música romântica e brega Bartô Galeno.
